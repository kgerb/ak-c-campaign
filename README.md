# SPP 2433 joint field campaign showcase

Static build of the interactive showcase for the April 2026 joint field campaign of working group C in the DFG Priority Programme SPP 2433 "Metrology on flying platforms".

Site: https://kgerb.github.io/ak-c-campaign/

The 3D point clouds here are reduced web copies for display. The campaign data are not released for download yet; a reviewed data release is in preparation.

Data sources: terrain and surface models © LGL Baden-Württemberg (www.lgl-bw.de, dl-de/by-2-0); GCG2016 height reference derived from work by BKG (CC-BY-4.0); base map © OpenStreetMap contributors.
